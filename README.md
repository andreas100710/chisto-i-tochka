# Сайт «Чисто и точка»

Одностраничный сайт химчистки мягкой мебели. Обычный HTML/CSS/JS, без сборки.

## Файлы

- `index.html` — тексты и блоки страницы
- `style.css` — оформление
- `main.js` — **настройки в самом верху**: телефон, WhatsApp, Telegram, Авито, услуги и цены
- `img/` — фотографии (пока пусто, на их месте бежевые заглушки)
- `serve.js` — локальный просмотр: `node site/serve.js` → http://localhost:4173

## Что заполнить

1. В `main.js`: `phoneText`, `phone`, `whatsapp` и цены `from` у каждой услуги.
2. В `index.html`: три отзыва с Авито (ищите `[ТЕКСТ ОТЗЫВА С АВИТО]`) и подписи к работам «До и после».
3. Положить фото в `img/` с такими именами (лучше JPG до 300 КБ, горизонтальные):

| Файл | Где на странице |
|---|---|
| `hero.jpg` | большое фото первого экрана (широкое, интерьер с диваном) |
| `dry.jpg` | карточка «Сушка входит в стоимость» |
| `stains.jpg` | карточка «Удаляем пятна и запахи» |
| `cta.jpg` | карточка «Пришлите фото — назовём цену» |
| `svc-sofa.jpg`, `svc-mattress.jpg`, `svc-chair.jpg`, `svc-carpet.jpg` | карточки услуг |
| `work-1.jpg` … `work-4.jpg` | «До и после» (вертикальные, 4:5) |

Фото до/после можно взять из Telegram-канала.

## Как опубликовать бесплатно

**Netlify Drop** (проще всего, 2 минуты): откройте app.netlify.com/drop и перетащите туда папку `site`. Получите адрес вида `имя.netlify.app`.

**GitHub Pages / Cloudflare Pages**: загрузите содержимое папки `site` в репозиторий и включите Pages.

Свой домен `.ru` (~169 ₽ первый год) подключается к любому из них в настройках.
